# اتصال Notion به اپلیکیشن پلنر (پنل ادمین)

این قابلیت اضافه شده: توی اپ، صفحه‌ی **پنل ادمین** یه بخش «همگام‌سازی از
Notion» داره. با زدن دکمه، برنامه‌هایی که توی همون دیتابیس Notion هستن که
بات تلگرامت (`bot.py`) ازش می‌خونه، به برنامه‌ی ادمین توی اپ اضافه می‌شن.

جهت حرکت داده یک‌طرفه‌ست: **Notion → اپ**. توی اپ چیزی به Notion نوشته
نمی‌شه (نوشتن به Notion فقط کار خودِ بات می‌مونه).

---

## چیزهایی که تغییر کرده

**بکند (`ApexplannerBackend`):**
- فایل جدید `app/notion_sync.py` — می‌ره دیتابیس Notion رو می‌خونه.
- دو اندپوینت جدید (فقط برای ادمین، با همون توکن JWT اپ):
  - `GET /admin/notion/status` — می‌گه Notion وصل هست یا نه.
  - `POST /admin/notion/sync` — همگام‌سازی رو انجام می‌ده.
- ستون جدید `notion_page_id` روی جدول `plan_items` (برای جلوگیری از
  ساختن آیتم تکراری در sync‌های بعدی). این ستون خودکار، موقع بالا اومدن
  سرویس، به دیتابیس موجودت هم اضافه می‌شه؛ کاری لازم نیست بکنی.
- `notion-client` به `requirements.txt` اضافه شده.

**فرانت‌اند (`ApexPlannerAPK`):**
- `api.js`: دو متد `adminNotionStatus()` و `adminNotionSync()`.
- `screens_admin.js`: کارت «همگام‌سازی از Notion» بالای لیست اعضا.

---

## راه‌اندازی روی Railway (بکند)

۱. کد جدید بکند رو دیپلوی کن (همون سرویسی که الان روی
`diplomatic-prosperity-production.up.railway.app` بالاست).

۲. توی تنظیمات همون سرویس (Variables)، این دو مقدار رو اضافه کن — **دقیقاً
همون integration و دیتابیسی که بات تلگرامت استفاده می‌کنه**، یعنی همون
مقادیری که برای `NOTION_TOKEN` و `NOTION_PLAN_DATABASE_ID` بات ست کردی:

```
NOTION_API_KEY=<همون NOTION_TOKEN بات>
NOTION_DATABASE_ID=<همون NOTION_PLAN_DATABASE_ID بات>
```

اگه integration بات از قبل به دیتابیس دسترسی داره، نیازی به کار اضافه‌ای
توی Notion نیست.

۳. سرویس رو ری‌استارت کن. با درخواست زیر می‌تونی چک کنی که تنظیمات درست
نشسته (نیاز به توکن ادمین داره؛ راحت‌تره از داخل خود اپ چک کنی):

```
GET /admin/notion/status
```

## استفاده توی اپ

۱. با اکانتی که `role = admin` داره وارد اپ شو.
۲. برو به پروفایل → پنل ادمین.
۳. بالای صفحه دکمه‌ی «همگام‌سازی الان» رو بزن.
۴. برنامه‌های Notion (همه یا بر اساس تاریخ، بسته به چی که بعداً بخوای
   فیلتر کنی) به لیست برنامه‌ی ادمین توی اپ اضافه/آپدیت می‌شن.

## نکته‌ی مهم درباره‌ی ساختار دیتابیس Notion

دیتابیس Notion باید همین property هارو داشته باشه (همونایی که بات هم ازش
استفاده می‌کنه):

| Property     | Type     |
| ------------ | -------- |
| Name         | Title    |
| Date         | Date     |
| Category     | Select   |
| Status       | Checkbox |
| StudyMinutes | Number   |
| TestCount    | Number   |
| Time         | Text     (اختیاری) |

آیتم‌هایی که تاریخ ندارن، در sync رد می‌شن (لاگ نمی‌شن، فقط نادیده گرفته
می‌شن) چون فیلد `date` توی مدل اپ اجباریه.

## امنیت

- کلید Notion فقط سمت بکند (متغیر محیطی Railway) نگه داشته می‌شه؛ هیچ‌وقت
  توی فرانت‌اند یا کد پابلیک قرار نمی‌گیره.
- اندپوینت‌های `/admin/notion/*` با همون سیستم auth موجود اپ محافظت
  می‌شن — فقط کاربری که `role=admin` داره و JWT معتبر داره می‌تونه صداشون
  بزنه.
