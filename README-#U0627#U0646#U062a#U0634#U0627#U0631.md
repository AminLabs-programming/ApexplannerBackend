# اپکس پلنر — راهنمای انتشار روی GitHub Pages و ساخت APK

این پوشه یک PWA کامل است که به یک بکند مشترک (که جداگانه روی Railway
دیپلوی می‌کنی) وصل می‌شه. قبل از آپلود، مرحله‌ی زیر رو انجام بده:

## مرحله‌ی صفر: تنظیم آدرس بکند

فایل `config.js` رو باز کن و این خط رو با آدرس واقعی بکندت (بعد از
دیپلوی روی Railway) عوض کن:

```js
const APEX_CONFIG = {
  BACKEND_URL: "https://YOUR-BACKEND-URL.up.railway.app",  // <- اینو عوض کن
};
```

اگه هنوز بکند رو دیپلوی نکردی، فعلاً همینطور رهاش کن — اپ لود می‌شه ولی
لاگین/ثبت‌نام تا وصل نکردن آدرس واقعی کار نمی‌کنه.

---

## بخش ۱: آپلود روی GitHub Pages (بدون نیاز به خط فرمان)

1. وارد [github.com](https://github.com) شو (اگه اکانت نداری، بساز — رایگانه).
2. گوشه‌ی بالا-راست، روی **+** بزن → **New repository**.
   - Repository name: مثلاً `apex-planner`
   - Public رو انتخاب کن (برای GitHub Pages رایگان لازمه)
   - دکمه‌ی **Create repository** رو بزن.
3. توی صفحه‌ی خالی ریپو، روی لینک **uploading an existing file** کلیک کن
   (یا از منوی Add file → Upload files).
4. تمام فایل‌های داخل این پوشه (`index.html`, `app.js`, `manifest.json`,
   `sw.js`, همه‌ی `screens_*.js`, `sheet.js`, و آیکون‌های `.png`) رو با
   drag & drop بریز داخل کادر آپلود. **پوشه رو آپلود نکن، فقط خودِ فایل‌ها.**
5. پایین صفحه دکمه‌ی سبز **Commit changes** رو بزن.
6. برو به تب **Settings** ریپو → از منوی سمت چپ **Pages** رو بزن.
7. زیر «Build and deployment» → **Source** رو بذار روی **Deploy from a branch**.
8. Branch رو `main` (یا `master`) و پوشه رو `/ (root)` انتخاب کن → **Save**.
9. چند دقیقه صبر کن. آدرس سایتت این شکلی می‌شه:
   ```
   https://USERNAME.github.io/apex-planner/
   ```
   (بالای همون صفحه‌ی Settings > Pages این آدرس رو نشونت می‌ده)
10. آدرس رو باز کن و مطمئن شو اپ درست لود می‌شه.

---

## بخش ۲: ساخت APK با PWABuilder

1. برو به [pwabuilder.com](https://www.pwabuilder.com)
2. آدرس GitHub Pages‌ت رو (مرحله‌ی ۹ بالا) توی کادر وارد کن → **Start**.
3. PWABuilder سه بخش رو می‌سنجه: **Manifest**، **Service Worker**، **Security**.
   با تنظیماتی که از قبل توی این پروژه گذاشته شده، باید امتیاز خوب/کامل بگیری.
4. برو به تب **Publish** → گزینه‌ی **Android** رو بزن.
5. فرم تنظیمات باز می‌شه:
   - **Package ID**: یه شناسه‌ی یکتا بده، مثلاً `com.apexplanner.app`
   - **App name / Short name**: از قبل پر شده (از manifest.json می‌خونه)
   - پایین فرم، گزینه‌ی **Signing key** رو روی **Create new** (یا "Signed")
     بذار — نه Unsigned — تا PWABuilder خودش کلید امضا بسازه و دیگه نیازی
     به امضای دستی نداشته باشی.
6. دکمه‌ی **Generate** رو بزن. چند لحظه صبر کن.
7. یک فایل zip دانلود می‌شه شامل:
   - فایل `.apk` (برای نصب مستقیم روی گوشی)
   - فایل `.aab` (اگه بعداً خواستی توی Google Play منتشر کنی)
   - کلید امضا (`.keystore` یا مشابه) — **این رو جایی امن نگه دار**،
     برای هر آپدیت بعدی اپ بهش نیاز داری.
   - فایل `assetlinks.json` و توضیح این‌که کجا آپلودش کنی (تا اپ نصب‌شده
     دیگه نوار آدرس مرورگر رو نشون نده و کاملاً native به نظر برسه).

---

## بخش ۳: نصب روی گوشی

1. فایل `.apk` رو با یو‌اس‌بی، تلگرام، ایمیل یا هر روشی به گوشی اندرویدت منتقل کن.
2. روی فایل بزن تا نصب بشه. اگه پیام «نصب از منابع ناشناس مسدود شد» اومد،
   برو تنظیمات گوشی → این مجوز رو برای همون اپ (مرورگر/فایل‌منیجر) فعال کن.
3. اپ نصب می‌شه و آیکونش روی صفحه اصلی میاد — دقیقاً مثل هر اپ دیگه.

---

## نکته درباره‌ی به‌روزرسانی بعدی

هر وقت خواستی تغییری توی اپ بدی:
1. فایل‌های جدید رو دوباره توی همون ریپوی گیت‌هاب آپلود کن (جایگزین فایل قبلی).
2. اگه فقط PWA (بدون نصب دستی APK) استفاده می‌کنی: کاربرها با باز کردن مجدد
   اپ، نسخه‌ی جدید رو خودکار می‌گیرن (به‌خاطر service worker).
3. اگه APK جدید هم می‌خوای: دوباره برو PWABuilder، همون Package ID رو بزن،
   و همون کلید امضای قبلی رو آپلود کن (نه کلید جدید) تا گوشی‌هایی که قبلاً
   نصب کردن بتونن به‌جای نصب مجدد، فقط آپدیت کنن.
